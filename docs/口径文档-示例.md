# 运营口径文档（示例）

> 这是给 Agent 检索用的**口径说明示例文档**，不是任何真实公司的制度。
> 作用：回答"复购率怎么算""活跃用户怎么定义"这类问题 ——
> 模型没见过这些口径就只能猜，猜出来的数字看着合理但口径是错的。
>
> 每篇用小标题（`##`）分开，检索时按小节切分。

## 行为类型口径

`user_behavior.behavior_type` 只有四个取值：

- `pv`：浏览，用户打开商品详情页
- `fav`：收藏，用户把商品加入收藏夹
- `cart`：加购，用户把商品加入购物车
- `buy`：购买，用户完成下单

统计任何指标前，先确认用的是哪个行为类型；同一用户可以对同一商品产生多次同类型行为。

## 转化率口径

转化率默认按**用户去重**计算，不按行为次数：

```
转化率 = 完成目标行为的去重用户数 / 完成起始行为的去重用户数 × 100%
```

例如"浏览到购买的转化率" = 有购买行为的用户数 / 有浏览行为的用户数。

**注意**：如果按行为次数算（购买次数 / 浏览次数），结果会低很多，两个口径不能混用。
报告里必须写明是"按人数"还是"按次数"。

## 活跃用户口径

活跃用户 = 在统计周期内**至少产生过一次行为**（pv / fav / cart / buy 任意一种）的用户。

- 日活跃（DAU）：`date_only` 当天的去重用户数
- 只浏览过一次、之后没有任何行为的用户，仍计入当天活跃，但不计入复购

## 高价值用户分层口径

按统计周期内的购买次数分层：

| 分层 | 规则 | 运营动作 |
|---|---|---|
| 核心 | 购买次数 ≥ 20 | 专属权益、新品优先体验 |
| 成长 | 购买次数 ≥ 5 | 提频、提升客单价 |
| 普通 | 购买次数 < 5 | 首购转化、复购引导 |

分层只看购买次数，不看金额（当前数据没有金额字段）。

## 加购未购买口径

"加购未购买"指用户对某商品有 `cart` 行为、但在统计周期内**从未对同一商品产生 `buy` 行为**。

- 商品维度：加购过但没人买的商品（用于找"挂了购物车却卖不动"的商品）
- 用户维度：加购过但什么也没买的用户（用于购物车召回）

两个维度结论不同，取数时要先确认问的是商品还是用户。

## 复购率口径

复购率 = 统计周期内**购买次数 ≥ 2 的去重用户数** / 有购买行为的去重用户数 × 100%。

- 只买一次的用户算新客，不算复购；
- 同一用户买同一商品多次，也算复购（当前口径不区分商品）；
- 如果要看"跨月复购"，需要按自然月切分统计周期后分别计算。
